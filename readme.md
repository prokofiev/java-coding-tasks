

## Задача Сервис приоритетов

Реализуйте сервис для управления очередью задач (Task Queue) с приоритетами.

### Требования:

1. Создайте класс `Task` с полями:
    - `id` (String) - идентификатор задачи
    - `name` (String) - название задачи
    - `priority` (int) - приоритет (1 - высший, 5 - низший)
    - `createdAt` (LocalDateTime) - время создания

2. Создайте класс `TaskQueueService` со следующими методами:
    - `void addTask(Task task)` - добавление задачи в очередь
    - `Task getNextTask()` - получение следующей задачи (самой приоритетной)
    - `boolean removeTask(String taskId)` - удаление задачи по ID
    - `List<Task> getAllTasks()` - получение всех задач в порядке приоритета
    - `int getTaskCount()` - получение количества задач в очереди

3. Валидация:
    - Приоритет должен быть в диапазоне 1-5
    - ID задачи не может быть null или пустым
    - Нельзя добавить задачу с уже существующим ID
    - При попытке получить задачу из пустой очереди должно бросаться исключение

### Логика приоритетов:
- Задачи с приоритетом 1 выполняются первыми
- При одинаковом приоритете - первая задача, которая была добавлена
- Метод `getNextTask()` удаляет задачу из очереди


### Тестовые случаи для проверки:
- Добавление задачи с валидными данными
- Добавление задачи с невалидным приоритетом (<1 или >5)
- Добавление задачи с пустым ID 
- Добавление задачи с дублирующим ID 
- Получение задачи из пустой очереди 
- Удаление существующей и несуществующей задачи 
- Правильность порядка задач по приоритету
- 
### Примеры для самопроверки:

```java
// Создание сервиса
TaskQueueService service = new TaskQueueService();

// Добавление задач
service.addTask(new Task("1", "Важная задача", 1, LocalDateTime.now()));
service.addTask(new Task("2", "Обычная задача", 3, LocalDateTime.now()));
service.addTask(new Task("3", "Срочная задача", 1, LocalDateTime.now()));

// Получение следующей задачи (должна быть одна из приоритета 1)
Task nextTask = service.getNextTask();

// Получение всех задач
List<Task> allTasks = service.getAllTasks(); // задачи отсортированы по приоритету

// Удаление задачи
boolean removed = service.removeTask("2"); // true

// Проверка количества задач
int count = service.getTaskCount(); // 1
```
